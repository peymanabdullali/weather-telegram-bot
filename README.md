# Weather Forecast Telegram Bot

## Description  
This Telegram bot is designed to inform users about **5-day** and **daily weather forecasts**. It integrates with the **Telegram API** for communication and the **OpenWeatherMap API** for retrieving weather data.

## Role  
**Backend Developer**

## Technologies and Tools  
- **Java**  
- **Gradle**  
- **Telegram API**  
- **OpenWeatherMap API**  
- **Feign Client**

---

## Features  
- Provides **daily weather updates** and **5-day forecasts**.  
- Interactive messaging via Telegram.  
- Seamless integration with OpenWeatherMap for accurate weather data.  

---

## Installation  

### Prerequisites  
- Java 17 or higher  
- Gradle installed  
- A Telegram bot token from the [BotFather](https://core.telegram.org/bots#botfather).  
- An OpenWeatherMap API key from [OpenWeatherMap](https://openweathermap.org/).
